# Dashboard

The dashboard is served by one view-shaped API request and refreshes every 30 seconds. It displays collected revenue, outstanding and overdue balances, expenses, net cash result, client count, a six-month revenue/expense trend, invoice-status distribution, receivables aging, client score leaders, revenue concentration, due-soon instalments, overdue invoices and the top client health register. All figures are computed from server records. Amounts that cannot be converted because no FX rate exists are excluded and disclosed.
