# Clients

The client list supports search, status filters through the API, pagination and a full detail dossier. Client detail includes the explainable eight-factor health score, penalties, invoices, payments, engagements and audit timeline. Client creation and editing use validated server endpoints. The Avoid API returns low-scoring or blacklisted clients with explicit recorded risk flags.
